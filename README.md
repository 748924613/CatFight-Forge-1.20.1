# CatFight Forge 1.20.1

适用于 **Minecraft 1.20.1 / Forge 47.x** 的猫咪对哈模组。两只猫靠近时会弓背、面对彼此、哈气并播放老吴音频。

## 功能

- 两只猫的精确距离不超过 5 格时进入对峙；对峙中不会乱跑，会面对对方并保持弓背、歪着抬头的姿势。
- 已驯服的猫会禁战，不会对峙、弓背、哈气或播放老吴音频。
- 对峙时会随机播放 3 段老吴音频；每段播放 10 或 15 秒后自动切换，并避免连续重复同一段。
- 对峙期间会屏蔽原版猫叫；任意一只猫死亡、离场或距离超过 5 格时，自定义音频会立即停止。
- 任意一只野猫只剩 1 心或更少时，对峙会暂停；两只猫停止哈气与攻击，每秒回复半颗心，双方满血后再恢复对峙。
- 猫有概率互相造成少量伤害。
- 猫会追逐 16 格内高速移动的矿车、奔跑的马、船和兼容的模组载具；真正撞上后会变成猫饼。
- 猫饼会以方头、长身、四条横腿和细尾巴的专用扁平轮廓显示，并保留原猫花色而不会出现透明缺块；它会完全固定在撞击位置、不能移动或转向，也不会参与对峙。用**空玻璃瓶**右键猫饼即可救回（玻璃瓶不会消耗）；十分钟无人救援会直接死亡。
- 新增 3 个物品：
  - **训猫棒**：攻击已驯服的猫后，禁止它对哈 3 分钟。
  - **小鱼干**：喂给已驯服的猫，可随机获得奖励。
  - **超级小鱼干**：永久禁止已驯服的猫对哈，并让它坐下。

## 安装

1. 安装 Minecraft 1.20.1 与 Forge 47.x。
2. 将构建产物 `catfight-1.3.18-forge-1.20.1.jar` 放进 `.minecraft/mods`。
3. 联机时服务端和所有客户端应安装相同版本。

## 从源码构建

需要 Java 17。

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/`。
